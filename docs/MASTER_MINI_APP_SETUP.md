# Журнал майстра — Telegram Mini App (/master)

Окрема, ізольована від CRM сторінка `https://p-3-0.vercel.app/master`: майстер бачить
лише свої записи на день, без доступу до решти адмінки. Вхід — автоматичний через Telegram,
без паролів.

## 1. Створити бота в BotFather

1. Напишіть [@BotFather](https://t.me/BotFather) → `/newbot`.
2. Назва, наприклад: `Журнал майстра`. Username, наприклад: `kresco_master_bot`.
3. Скопіюйте виданий токен.

## 2. Налаштувати env у Vercel

Додайте змінну середовища (Production + Preview, якщо потрібно):

```
TELEGRAM_MASTER_BOT_TOKEN=<токен з BotFather>
```

Задеплойте проєкт, щоб змінна підхопилась.

## 3. Прив'язати вебхук бота

Викличте один раз (підставте токен):

```
https://api.telegram.org/bot<ТОКЕН>/setWebhook?url=https://p-3-0.vercel.app/api/telegram/master-bot-webhook
```

Перевірити статус:

```
https://api.telegram.org/bot<ТОКЕН>/getWebhookInfo
```

## 4. Увімкнути кнопку Menu Button (опційно, для зручності)

У BotFather: `/mybots` → оберіть бота → `Bot Settings` → `Menu Button` → `Configure Menu Button`:
- Текст: `Мій журнал`
- URL: `https://p-3-0.vercel.app/master`

Це додає постійну кнопку відкриття журналу поруч з полем вводу повідомлення — додатково
до кнопки, яку бот надсилає у відповідь на `/start`.

## 5. Прив'язати майстра (адмін)

1. У розділі «Команда» (`/admin/team`) відкрийте картку майстра.
2. Заповніть поле **Telegram username** (без `@`) — саме той username, яким майстер
   користується в Telegram.
3. Переконайтесь, що в картці вказано **Altegio staff ID** (`altegioStaffId`) — без нього
   журнал не знає, які записи належать цьому майстру.

## 6. Майстер підключається

1. Майстер знаходить бота в Telegram і надсилає `/start`.
2. Бот звіряє його Telegram username з карткою в «Команда»:
   - якщо збіг знайдено — бот зберігає `chatId` і надсилає кнопку «Мій журнал»;
   - якщо збігу нема — бот просить звернутись до адміністратора (крок 5 не виконано
     або username відрізняється).
3. Натискання «Мій журнал» відкриває `/master` прямо в Telegram (Mini App), без логіну.

## Технічні деталі (для розробника)

- Авторизація — через `initData` Telegram WebApp (підпис HMAC-SHA256 бот-токеном),
  перевіряється в [`web/lib/telegram/verify-webapp-init-data.ts`](../web/lib/telegram/verify-webapp-init-data.ts).
  Токен не передається нікуди і не логується.
- API `/api/master/appointments` і сторінка `/master` **не проходять** через
  `web/middleware.ts` (не входять у matcher `/admin/:path*`) — не мають жодного спільного
  стану з admin-сесією.
- Дані — лише читання: час, клієнт, телефон, послуги, статус відвідування. Без сум оплат,
  без редагування, без чекауту.
