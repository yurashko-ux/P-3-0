# Аналіз переписок лідів: статус, коментар, нагадування

## Зараз — вручну (за запитом у Claude Code)
Користувач час від часу просить «проаналізуй нові та оновлені переписки лідів».

Порядок:
1. Вибрати переписки з новими повідомленнями після останнього аналізу (див. журнал нижче).
   Джерело — `direct_messages` (source `instagram_graph`, `manual`, `instagram_comment`), з 15.10.2026 (раніше — лише вхідні ManyChat).
2. Постійних клієнток (корекції, оплати, тест) не чіпати — лише ліди.
3. Статус — з набору лідів (`direct_chat_statuses.scope = 'lead'`), коментар — коротко суть і результат
   (`consultationListComment`), нагадування — дата із суті розмови (`callbackReminderKyivDay` + історія).
4. Спершу показати список на погодження, потім записати. Зміну статусу логувати в
   `direct_client_chat_status_logs` (`changedBy = 'аналіз переписок'`).
5. Правила запису: не перезаписувати коментар, написаний людиною; не міняти майбутнє нагадування;
   «Не з'явилась» / «Скасувала» — статус лишається, плюс нагадування, щоб довести до консультації.
6. Оновити журнал нижче.

## Пізніше — автоматично (відкладено: Claude API платний)
- Cron на Vercel раз на 6 годин: `/api/cron/lead-chat-analysis`.
- Аналіз лише змінених переписок через Claude API (Haiku, за потреби Sonnet), структурована відповідь
  {статус, коментар, дата нагадування}; запис одразу, без режиму перевірки.
- Потрібен `ANTHROPIC_API_KEY` у Vercel (користувач додасть сам).
- Не перезаписувати статус, змінений адміністратором після останнього аналізу.
- Відкрите питання: чи AI міняє майбутнє нагадування, якщо розмова змінилась.
- UI: позначка ✨ біля статусу від AI, підказка «Поставив AI …», коротка історія змін у попапі статусу.
- Потрібне поле в картці «коли востаннє аналізували» (міграція).
